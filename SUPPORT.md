# Support

## Where To Ask

GitHub Issues on this repository is the place for:

- bug reports,
- feature requests,
- questions about using the solver,
- packaging or release trouble.

A good report names the command you ran, includes something that reproduces the
behavior, and states the commit or release you were on.

## Security Reports

Suspected vulnerabilities should not go through public issues. See
[`SECURITY.md`](SECURITY.md) for the private reporting process.

## What To Expect

This is a best-effort project. There are no response-time guarantees or formal
support agreements.

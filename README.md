# ay

Fast, proof-carrying SAT/SMT/CHC solver. Inspired by Z3.

ay is made by [ALab](https://alab.systems). Its source code is not published:
this repository carries ay's binary releases, their release notes, and its
license.

## Install

Install it with aterm's package manager, which verifies every signed binary:

```sh
aterm pkg install ay
```

Every release is listed under [Releases](https://github.com/alabsystems/ay/releases),
and its notes are in `release-notes/`.

## Security

Report a security problem privately to hello@alab.systems, not in a public
issue.
